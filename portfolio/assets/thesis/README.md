# Thesis PDF

Place your thesis files here:

| File | Format | Usage |
|------|--------|-------|
| `luca-muroni-thesis.pdf` | Standard PDF | **Use this one** — linked from the portfolio (browser preview, download) |
| `luca-muroni-thesis-pdfa.pdf` | PDF/A (optional) | Long-term archival copy; not linked on the site |

## Recommendation

Save the **normal PDF** as `luca-muroni-thesis.pdf`. It opens reliably in browsers and is usually smaller.

Keep PDF/A in the repo only if you want an archival copy alongside the web version.

## Read on the site

The portfolio links to `thesis.html`, which embeds the PDF in the browser. If embedding fails (some mobile browsers), use **Open in tab** or **Download PDF**.

## After adding the file

1. Copy `luca-muroni-thesis.pdf` into this folder
2. Refresh the site — links appear in **Education** and **Selected work**
3. Commit and push
